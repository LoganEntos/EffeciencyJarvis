## Phase A — rebuild the self-improvement loop (root-cause order)

Full diagnosis + line refs in `docs/audit-2026-07-23-self-improvement-loop.md`.
State today: autopilot enabled but starving since 07-14 (backlog has zero open
⬜ table rows and nothing ever adds any); `data/schedules.json` is empty (the
6h orchestrator was a one-shot that expired 07-19); no continuation on
context-death; tasks/schedules can't pass effort.

- **A1 — backlog format rule (5 min).** Top of `docs/improvement-backlog.md`:
  open items MUST be `| id | loc | issue | fix | effort | risk | ⬜ |` table
  rows (the only shape `lib/autopilot.js parseBacklog()` reads); bullets are
  history only.
- **A2 — autopilot falls back to the task queue.** In `pickNext()`
  (lib/autopilot.js): when no open backlog row exists, pick the first
  never-run task from `lib/tasks.js load()` (no runId, and skip
  `source:'autopilot'` to avoid self-loops) and dispatch it through the
  existing task path. Makes the Tasks tab the one visible queue.
- **A3 — scout + standing orchestrator schedule.** Seed (via
  `POST /api/schedules`, or a boot-time seed-if-missing in lib/schedules.js)
  one **disabled-by-default** schedule: every 12 h, a scout run whose prompt
  is the FIND step of `docs/handoffs/improvement-cycle.md` — sweep the repo,
  append new ⬜ rows to the backlog (per A1) or enqueue hub tasks, fix
  nothing itself. Its prompt must state it may use web research (scraper /
  web-researcher agents) for prior art. The user arms it with one toggle.
- **A4 — effort through tasks + schedules.** Add optional `effort`
  (validated against `EFFORTS` in lib/runs.js) to task and schedule records;
  thread through `runTask()`/`runAll()`/`fire()` into `startRun()`. Autopilot
  dispatches default to `model:'opus'` + `effort:'high'` for code fixes.
- **A5 — continuation on context-death.** In `finalizeRun()`
  (lib/runs-engine.js): if the run ended `error` with a captured `sessionId`
  AND originated from a task/schedule/autopilot (thread a `source` through
  startRun meta), auto-enqueue ONE continuation run with `--resume` and a
  "context was cut — read the log/diff, finish ONLY the current item" prompt.
  Cap: `meta.continuations` ≤ 2 per chain. Never continue user-cancelled runs.
- **A6 — starvation visibility.** When an enabled autopilot tick finds
  nothing to dispatch (backlog empty AND no eligible task), surface it: a
  status field the Config panel renders as a badge ("autopilot idle — queue
  empty"), instead of today's silent idling.
